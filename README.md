# LunarSpark: Echoes Beyond Earth

**Live site:** https://vismaym86.github.io/LunarSpark/

LunarSpark is our entry for the **NASA Space Apps Challenge** challenge *Abandoned but not Forgotten: Storytelling about NASA's Discarded Equipment on the Moon and Mars*.

It is a multi-page website that tells the life story of 13 groups of NASA equipment left on the Moon, on Mars and in deep space, from first design to last signal.

## What it does

- Tells the story of each machine on its own page, with the same seven chapters: overview, where it began, the mission, how it worked, what it found, why it was left behind and where it is now.
- Shows key facts, a specifications table, a timeline of events and NASA photographs for every machine.
- Lets visitors filter the fleet by Moon, Mars or deep space, and search by name.
- Includes a timeline page showing when each machine last spoke, in order.
- Works on laptops and phones, and respects the "reduce motion" setting.

## Run it locally

No build step or install is needed.

1. Download or clone this repository.
2. Open `index.html` in a browser, or use a local server such as the VS Code Live Server extension.

## Built with

- HTML, CSS and plain JavaScript (no frameworks)
- Canvas for the animated starfield
- Intersection Observer for scroll effects
- Google Fonts: Fraunces and Sora
- Hosted on GitHub Pages
